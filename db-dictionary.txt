THIS TEXT FILE IS TO KEEP TRACK OF WHAT EACH TABLE IN THE DATABASE DOES AND WHERE IT COMES FROM

goalie_stats: a collection of players with non N/A values under the feature 'saves'
this table comes from filtering our PitchAPI raw JSON

outfield_players: the collection of premier league outfield players and their stats
for the 2025/2026 season
this table comes from filtering our PitchAPI raw JSON for playes with NaN feature 'saves'

outfield_season_stats: 

player_match_stats: dataset of all the players match stats for every match in the premier league 25/26 season
this table comes from looping through every match id from the premier league for 25/26


transfermarkt_values: dataset of tens of thousands of players and their transfer history
this comes from a dataset I found on github @: https://github.com/dcaribou/transfermarkt-datasets
script origin : dataset_import.py 

transfermarkt_players: dataset of around 50,000 players and their characteristics (age, doB, etc)
also came from: https://github.com/dcaribou/transfermarkt-datasets
script origin : dataset_import.py

merged_transfermarkt: dataset of the combination of transfermarkt_players and transfermarkt_values
with only the features that we need
script origin : player_info.py

player_ml_data_league_season(configurable): dataset of the players and their info/values
script origin : player_info.py
